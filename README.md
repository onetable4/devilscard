# Devil's Card

26장의 카드 중 제시된 조건을 **모두** 만족하는 **단 하나의 4장 조합**을 찾는 웹 추리 퍼즐.

## 실행

빌드나 서버가 필요 없어요. `index.html`을 브라우저로 열면 바로 플레이할 수 있어요.

```bash
open index.html                 # macOS
# 또는 로컬 서버로
python3 -m http.server 8000     # → http://localhost:8000/#322
```

## 규칙

- 카드 A~Z에는 순서대로 1~26이 적혀 있고, 6열로 놓여요.
- 각 카드는 색깔(초록·노랑·파랑·핑크·보라) 1개와 문양(다이아·하트·네모·별·동그라미) 1개를 가져요.
- 조건 4~7개를 모두 만족하는 4장은 정확히 한 조합뿐이에요. 4장을 골라 제출하면 승리예요.
- **n번째**: 고른 4장을 작은 수부터 늘어놓았을 때의 순서예요. **차**는 큰 수 − 작은 수예요.
- 틀리면 어떤 조건에 어긋났는지 표시돼요.

### 조건 유형

| 유형 | 예시 | 퍼즐당 최대 |
|---|---|---|
| `sum` 합 | 네 카드의 합은 53이다 / 48 이상 60 이하이다 | 1 |
| `pair` 두 카드의 합·차·곱 | 첫 번째와 네 번째 카드의 곱은 100이다 | 3 |
| `kinds` 종류 수 | 네 카드에 사용된 문양은 3가지이다 / 색깔이 모두 다르다 | 2 |
| `rank` 보드 순위 | 두 번째 카드의 색깔은 보드 전체에서 가장 적은 색깔이다 | 2 |
| `same` 같음/다름 | 두 번째와 세 번째 카드는 문양이 같다 | 2 |
| `parity` 홀짝 | 홀수 카드는 세 장이다 | 1 |
| `grid` 줄 | 두 번째와 네 번째 카드는 같은 세로줄에 있다 | 1 |

한 퍼즐에는 최소 3가지 유형이 섞이고, 숫자 조건(`sum`/`pair`)과 색깔·문양 조건(`kinds`/`rank`/`same`)이 각각 1개 이상 들어가요.

## 퍼즐 생성 방식

4장 조합은 C(26,4) = **14,950가지**뿐이라, 모든 조합을 직접 대입해 해가 하나인지 바로 검증할 수 있어요. 미리 만든 문제 목록 없이 **퍼즐 번호를 시드로** 그때그때 생성하고, 같은 번호는 항상 같은 퍼즐이 돼요.

1. **보드**: 색깔·문양별 장수를 5종 모두 다르게 배정해요(예: 9/6/5/4/2). 그래서 "가장 많은" 같은 순위에 동점이 없어요.
2. **정답**: 4장을 무작위로 골라요.
3. **후보 조건**: 정답에 대해 참인 조건을 모두 만들어요(약 60개).
4. **선택**: 남은 후보를 15~70%로 줄이는 조건을 고르되, 유형을 먼저 고른 뒤 그 안에서 조건을 골라 한 유형으로 쏠리지 않게 해요. 해가 1개가 될 때까지 반복해요.
5. **최소화**: 빼도 해가 하나로 유지되는 조건은 제거해요. 남은 조건은 모두 필수예요.
6. **검사**: 개수(4~7)와 유형 규칙을 통과하지 못하면 다시 만들어요. 마지막으로 판정 함수로 처음부터 다시 세어 유일 해를 확인해요.

- **오늘의 퍼즐**: 2026-01-01이 #1이고, 하루에 1씩 늘어요.
- **주소**: `index.html#번호`로 특정 퍼즐을 공유할 수 있어요.
- **번호 범위**: 화면에서는 **#1~#99999**만 열 수 있어요(`js/app.js`의 `MAX_PUZZLE`). 범위 밖 번호를 입력하면 거부하고, 범위 밖 주소로 들어오면 오늘의 퍼즐을 열어요. 엔진 자체는 더 큰 번호도 생성할 수 있어요.

## 파일 구조

```
devilscard/
├── index.html        # 화면 구조, 문양 SVG, 도움말/결과 다이얼로그
├── css/style.css     # 스타일 (라이트/다크, 모바일 하단 고정 입력창)
├── js/engine.js      # 퍼즐 엔진: 시드 RNG, 보드·조건 생성, 판정, 문장화 (DOM 없음, Node 공용)
├── js/app.js         # 화면 렌더링, 입력 처리, 진행 저장(localStorage)
└── tests/verify.js   # 엔진 검증 스크립트
```

## 조작

- 퍼즐을 열면 조건과 카드가 블러로 가려져 있고 시간도 멈춰 있어요. **시작하기**를 누르거나 <kbd>Enter</kbd>/<kbd>Space</kbd>를 누르면 공개되고 시간이 흘러요.
- ❚❚ 버튼을 누르거나 다른 탭·앱으로 가면 자동으로 일시정지되고 다시 가려져요. **계속하기**를 누르면 이어서 진행해요. 진행 중이던 퍼즐을 다시 열 때도 **계속하기**부터 시작해요.
- 카드 클릭 또는 키보드 알파벳으로 선택해요(한글 입력 상태도 OK). <kbd>Enter</kbd>로 제출, <kbd>Backspace</kbd>로 마지막 선택을 취소해요.
- **✕ 지우기** 모드, 마우스 오른쪽 클릭, 길게 누르기 중 하나로 후보에서 뺀 카드를 표시해요.
- 조건을 클릭하면 줄을 그어 메모할 수 있어요.
- 범례(색깔·문양)를 클릭하면 해당 카드만 강조돼요. **장수 표시**를 켜면 종류별 장수가 보여요.
- 진행 상황(시도, ✕ 표시, 줄 긋기, 해결 여부, 시간)은 브라우저에 퍼즐 번호별로 저장돼요.

## 검증

```bash
node tests/verify.js 500
```

퍼즐 1~500번에 대해 다음을 검사해요.
- 유일 해이고 정답과 일치하는지
- 모든 조건이 필수인지
- 조건 개수와 유형 규칙을 지키는지
- 장수에 동점이 없는지
- 같은 번호에서 같은 퍼즐이 나오는지(결정성)

현재 결과는 실패 0건이에요. 생성 시간은 평균 약 12ms이고, 조건 개수는 4개 13%, 5개 33%, 6개 36%, 7개 19%예요.

## 조정 포인트

`js/engine.js` 상단 상수:
- `MIN_CLUES` / `MAX_CLUES`: 조건 개수 범위
- `TYPE_LIMIT`: 유형별 최대 등장 수
- `GOOD_MIN` / `GOOD_MAX`: 조건 하나가 후보를 줄이는 "적당한" 비율

> 상수를 바꾸면 같은 번호라도 다른 퍼즐이 생성돼요(이미 공유된 번호의 퍼즐이 바뀜).
